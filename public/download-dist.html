Baixe o site do My Doctor empacotado para subir

Este botão monta, direto no seu navegador, o arquivo mydoctor-site.zip com tudo o que o site precisa para rodar na Hostinger: página, código, ícone, configuração de segurança (.htaccess) e as instruções de instalação. Nenhum dado seu é enviado a lugar nenhum — o ZIP é gerado localmente.

Clique para empacotar e baixar o site completo.

versão v0.2.0 arquivos — tamanho — pwa instalável + offline

Depois de baixar — na Hostinger

1

hPanel → Websites → Gerenciar (mydoctor.med.br) → Arquivos → Gerenciador de Arquivos → abra a pasta public_html.

2

Apague o default.php / index.html de exemplo da Hostinger, se existir. Ative “mostrar arquivos ocultos” na engrenagem.

3

Clique em Enviar arquivos, escolha o mydoctor-site.zip e depois clique com o botão direito nele → Extrair (extraia para dentro de public_html).

4

Segurança → SSL → Instalar SSL (grátis). Espere alguns minutos e acesse https://mydoctor.med.br — deve abrir com o cadeado 🔒.
